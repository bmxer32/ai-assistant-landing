# Обложки для объявлений на Avito

Шесть картинок 2400×1800 (4:3 — соотношение, которое просит Avito) в стиле
лендинга: Unbounded для заголовков, толстая чернильная обводка, жёсткая тень
без размытия, лёгкие наклоны.

| Файл | О чём | Какое возражение снимает |
|---|---|---|
| `avito-1-glavnaya.png` | Отвечает клиентам за вас | «Что это вообще такое» |
| `avito-2-noch.png` | Продаёт, пока вы спите | «Ночью всё равно никто не пишет» |
| `avito-3-skorost.png` | 3 секунды против 2 часов | «Я и сам отвечаю» |
| `avito-4-zapusk.png` | Запуск за один день | «Долго внедрять, некогда» |
| `avito-5-cena.png` | Дешевле полставки администратора | «Дорого» |
| `avito-6-avito.png` | Кто ответил сразу — тот и продал | «А на Avito сработает?» |

Ставьте в объявление несколько сразу: первой — первую или шестую, дальше
по порядку. Avito показывает превью квадратом, поэтому главное всегда
в левой половине картинки.

## Как пересобрать

Все шесть свёрстаны в одном файле `covers.html` — стиль правится в одном
месте и не разъезжается между картинками.

```bash
npm i puppeteer-core
node render.js
```

Путь к Chrome при необходимости: `CHROME=/path/to/chrome node render.js`.

Шрифты подключаются локально из `../fonts/`, рендер ждёт `document.fonts.ready` —
иначе снимок уходит с системным шрифтом вместо Unbounded.

## Текст объявления

Заголовок (до 50 знаков), варианты:

```
AI-ассистент отвечает клиентам за вас 24/7
Чат-бот с ИИ для бизнеса — запуск за 1 день
Ассистент для Avito: отвечает за 3 секунды
```

Тело:

```
Настраиваю AI-ассистента, который отвечает вашим клиентам
в Telegram, WhatsApp, на сайте и в Avito — круглосуточно,
по вашему прайсу и вашими словами.

Что делает:
• отвечает на вопросы о ценах, сроках и наличии
• записывает клиентов и принимает заказы
• присылает вам отчёт о переписках
• сложные вопросы передаёт живому человеку

Как запускаем:
1. Присылаете прайс, ссылку на сайт или просто голосовое
2. Обучаю ассистента на ваших материалах — обычно за день
3. Тестируете сами, как клиент. Понравится — подключаем каналы

Демо бесплатно и на ваших данных: соберу ассистента
по вашему прайсу, потыкаете — потом решите.

Стоимость от 5 900 ₽/мес, запуск 3 000 ₽.
Подробности: narodniy-team.ru/ai
```

Категория: «Услуги» → «Деловые услуги» → «IT, интернет, телеком».

Размещать имеет смысл сразу в нескольких городах — услуга удалённая,
география не важна.

## Что важно помнить

Цифр чужих продаж на обложках нет намеренно: заявления о результатах
услуги должны быть подтверждаемыми, иначе это недостоверная реклама
по ФЗ «О рекламе». Всё, что написано, относится к возможностям продукта
и к вашему собственному прайсу — это подтверждается.

Появятся реальные внедрения с согласием клиента на публикацию —
можно будет добавить обложку с настоящими цифрами и ссылкой на отзыв.
